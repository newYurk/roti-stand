# North star — «о чём игра»

> Рабочая фиксация после разбора 23.09.2026. Не заменяет `roti-design-doc.md`; сужает **эмоцию**
> и **порядок v0 → v1**, пока владелец не пересмотрит одной строкой (⚑).

## Выбор

| Слой | Star | Одна фраза |
|------|------|------------|
| **v0 (эмоция)** | **B — «Вечерняя смена у одной тавы»** | Я не оптимизирую заказы — я провожу вечер у тавы: N шариков теста, N тихих встреч. |
| **v1 (глубина)** | **A — «Узнавание по запаху и форме»** | Деревня не объясняет словами; я учусь читать жесты и подбирать роти. |
| **Отложено** | C — «Музей ambient на колёсах» | Только если явно захочется collectathon по локациям; иначе раздувает scope. |

**Почему B сначала:** ядро (тесто, тава, звук) уже несёт «неспешность 90‑х» без ходилки; мета-слой в голове не складывался, потому что в доках одновременно карта, каталог, обещания и год сюжета. v0 = **один фон, один цикл гость → роти → жест → предмет**.

**Почему A следом:** это уже ближе к корпусу (книга без слов, след роти, «вкусовое расследование»), но требует памяти между днями — после того как цикл B ощущается на пальцах.

## Гости (v0)

**Живые люди** — как в одобренных mockups (пожилая у воды, турист на ночном рынке, школьница).

- **Не канон v0:** «готовлю для призраков» — метафора неясного «кому», не дизайн.
- **Призраки / память места** — запасной поворот только если владельцу важна линия угасшей бабушкиной улицы; тогда это **память, не horror**, та же механика без текста.

## Что сознательно не делаем (пока)

- Деньги, минуты, энергия, невидимые штрафы.
- Сюжетные реплики ради ясности.
- Симуляция ходьбы по улицам / платформер.
- Полная карта и рост NPC до проверки одного бессловесного цикла — см. `docs/v0-guest-screen.md`.

## Pitch (один абзац)

Вечер на тропическом острове: тележка с роти, одна вогнутая тава, дождь по тенту. Ты растягиваешь тесто шлепками, ловишь готовность на слух, прижимаешь пузыри пальцем. Люди подходят без разговоров — показывают, чего хотят, жестом отвечают на твоё блюдо и оставляют на стойке то, чем живёт деревня. День кончается, когда кончается заготовленное тесто; тележка постепенно становится музеем этих встреч, не магазином улучшений.
