# Официальные скилы Claude Code для Roti Stand

Составлено 25.08.2026 по вопросу «какие официальные скилы полезны при разработке Roti».
Привязано к стадии проекта на эту дату: доки и развилки, из кода — только стенд
`roti-dough-proto`. При смене стадии (выбор стека, арт-стиля) список пересмотреть.

Официальные скилы существуют в трёх видах: **встроенные** в Claude Code (работают сразу),
**устанавливаемые** из репозитория `anthropics/skills` и **плагины** из официального
маркетплейса `claude-plugins-official`.

## Встроенные — полезны прямо сейчас

- **`/code-review`**, **`/simplify`** — ревью и чистка кода стенда. Особенно при переходе
  на шлепковый ввод по `slap-input-audit.md`: state machine из шести состояний — ровно
  тот код, где ревью окупается.
- **`/dataviz`** — графики результатов замеров из рамки `DECISION.md` (задержка звука
  ≤20 мс, джиттер, узлы сетки теста) и трёх проходов экспериментов со стоп-правилами.
- **`/design`** — макеты экранов и UI. **Не раньше решения по арт-стилю**: `mockups/`
  до него не заводится (см. `STATE.md`, «Осторожно»).
- **artifact-design** — уже в работе: обзорный артефакт «Roti Stand» сделан через него.
- Браузерная автоматизация (chrome-devtools MCP) — не скил, но главный инструмент живого
  теста стенда; по правилам `Home/CLAUDE.md` — отдельное окно, `--isolated`.

## Устанавливаемые (репозиторий anthropics/skills)

В репозитории 17 скилов; под Roti имеют смысл два-три:

- **`webapp-testing`** — тестирование веб-приложений; подходит стенду (Canvas, дальше WebAudio).
- **`frontend-design` / `canvas-design`** — дизайн UI; актуально после решения по арт-стилю.
- Остальное (docx/pdf/pptx/xlsx, brand-guidelines, slack-gif-creator, mcp-builder и т.п.) — не про игру.

Установка:

```
/plugin marketplace add anthropics/skills
/plugin install webapp-testing@anthropics/skills
```

Либо вручную: скопировать папку скила в `~/.claude/skills/` (глобально)
или `.claude/skills/` в проекте.

## Плагины официального маркетплейса — после выбора стека

Маркетплейс `claude-plugins-official` подключается автоматически; каталог — команда
`/plugin`, вкладка Discover.

- **LSP-плагины**: TypeScript — если победит веб-стек; C++ — если Godot с GDExtension
  (условие для Godot по ревью 21.08.2026: GDScript не тянет ~1 000–1 200 узлов сетки).
- **`github`** — работа с репозиториями.

## Оговорки

- Состав 17 скилов подтверждён частично по сторонним обзорам, не только по репозиторию —
  перед установкой проверить вживую через `/plugin`.
- Скилы не двигают текущий этап: узкое место — 92 развилки, ждущие решений владельца,
  и живой тест шлепка. Скилы выстрелят на этапах 6–7 плана (замеры и прототип).
