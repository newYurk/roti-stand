Погода на острове — главный драматург смены:

```
+-------------------+      +--------------------+      +--------------------+
| УТРЕННИЙ ТУМАН    | ---> | ПОЛУДЕННЫЙ ЗНОЙ    | ---> | ВНЕЗАПНЫЙ ЛИВЕНЬ   |
| (прохлада, покой, |      | (сухой воздух,     |      | (барабан по тенту, |
|  медленный пар)   |      |  жажда тени)       |      |  гости под крышей) |
+-------------------+      +--------------------+      +--------------------+
                                                                  |
                                                                  v
                                                       +--------------------+
                                                       | СУМЕРКИ И БРИЗ     |
                                                       | (янтарные фонари,  |
                                                       |  ночные беседы)    |
                                                       +--------------------+
```

1. **Утренний речной туман (05:30 – 08:00):**
   - Рассеянный золотистый свет, холодная роса, шёпот воды.
   - Тесто максимально податливое и нежное. Пар над тавой поднимается ровными высокими столбами.
   - Приходят рыбаки перед выходом в море ([Дядюшка Чат](<../01 Люди/Дядюшка Чат.md>)). Заказы сытные, согревающие.
2. **Полуденный зной (11:30 – 14:00):**
   - Слепящее белое небо, стрёкот цикад, горячий воздух дрожит над дорогой.
   - Тесто быстрее сохнет — его нужно прикрывать влажным льняным полотенцем. Полотняный навес макашницы даёт желанную тень.
   - Школьники на перемене ([Малышка Плой](<../01 Люди/Малышка Плой.md>)). Быстрые сладкие роти-кульки на ходу.
3. **Внезапный тропический шквал / Ливень (Downpour):**
   - Небо темнеет за 5 минут, стена тёплого ливня.
   - Барабанный бой капель по ткани навеса, шипение брызг о раскалённую кратху: `*пшшш-тссс*`.
   - **Механика «Все под одним навесом»:** прохожие набиваются под крышу макашницы. Завязываются перекрёстные диалоги между персонажами, которые обычно не общаются (Чат ворчит, но достаёт сухое полотенце для промокшей Плой).
4. **Сумерки и вечерний бриз (17:30 – 20:00):**
   - Фиолетово-малиновый закат, первые звёзды.
   - Зажигается керосиновый фонарь, бросая янтарные блики на полированную сталь стола.
   - Время длинных разговоров у откидного столика под шелест ночного прилива.
5. **Сезоны года:**
   - *Сухой сезон:* ярмарки, туристы с паромов, много заказов, звон колокольчика.
   - *Муссоны (Сезон дождей):* туристы уезжают, остров отрезан от материка. Время сокровенных историй, рассказов про бабушку и тишины.

## Что здесь спорит с принятым

- **Погода меняет тесто** (податливее утром, сохнет в зной) — в модели стенда такого входа нет вовсе.
- **Тесто прикрывают влажным полотенцем**, а по фактчеку и дизайн-доку шарики отдыхают в масле.
- **Гости расписаны по часам суток** — это ответ на вопрос, который держит открытым
  [#63](https://github.com/newYurk/roti-stand/issues/63).
- Два сезона с механическими последствиями против «в v1 — один сезон».
