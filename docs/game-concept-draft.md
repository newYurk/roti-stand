# Roti Stand — концепция игры целиком (черновик)

> **Статус.** Черновик Claude 17.11.2026, не решение владелицы; проверяется игрой.
> Собран из пяти независимых набросков и их взаимной критики. Все минуты и дни ниже — оценка, не замер.
> Опирается на рабочую гипотезу 16.11 (`runs/concept-2026-11-16.md`): короткий вечер, три шарика, один молчаливый гость, страница тетради.

## Одной фразой

Короткий вечер у тавы: три шарика теста и один молчаливый человек, который ест твоё роти и телом показывает, что он в нём заметил. Третий шарик — ничей. Каждый следующий вечер отличается одной вещью, которую оставили люди.

## Что делает игрок

**Минута (одно роти, 3–5 минут)**

1. Беру шарик из миски. Миска — единственный счётчик: видно, сколько осталось.
2. Плющу, тяну, отправляю на таву — как в нынешнем стенде.
3. Пока роти жарится и руки свободны, подходит гость и показывает один жест (Сом стучит костяшками по краю тавы). Тронула гостя — он повторил жест.
4. Складываю, режу. Подаю отдельным жестом: веду тарелку пальцем к человеку (не взмахом — взмах занят тавой).
5. Гость ест. Ответ — звук укуса, лицо, крошки; он обязан читаться и без звука. Ответов три, оценки нет: «узнала своё», «вежливо съела», «удивилась».
6. На стойку ложится еда: варенье или бананы. Что-то остаётся при любом ответе.
7. Тетрадь приоткрывается сама: слева рисунок Мали про этого человека, справа снимок моего настоящего роти. Разницу видно глазами.

**Вечер (10–15 минут)**

- Шарик 1 — гостю.
- Шарик 2 — второй шанс: если Сом съела вежливо, она не уходит, можно попробовать иначе.
- Шарик 3 — ничей: псу, себе или оставить на ограде. Место для проб без зрителя.
- Небо темнеет на тон с каждым взятым шариком, а не от минут. Таймера нет.
- Миска пуста — накрываю таву крышкой. Ночь: снимки вечера и одна перемена на тележке.

**Неделя**

- Вчерашняя еда лежит на полке как начинка или полив, и её видимо мало: два банана на трёх едоков — кому?
- Тот же человек приходит в другом состоянии (с зонтом, с пустой банкой): вкус тот же, вечер другой.
- Новые люди приходят как следствие моих поступков: повесила колокольчик — на звон прибегает Плой.

| 0:20 | Беру первый шарик. Плющу, тяну, на таву. |
| ~1:30 | Во время жарки подходит Сом, стучит по краю тавы. |

**Выход в любой момент.** Сохранение само, после каждого шага. Свернула приложение или позвонили — на таву ложится крышка, жарка стоит. Вернулась через минуту или через неделю — сняла крышку и продолжила. Ничего не сгорает, никто не напоминает, что «не доиграла».

## Экраны и меню

Меню как отдельных экранов нет: всё служебное — предметы тележки. Экранов пять, все вертикальные.

**1. Тележка в сумерках** — вместо главного меню; она же показывает, что накопилось. Вход один: лампа.

```
+--------------------+
|  .   сумерки   .   |
|   (лампа) не горит |
|  ________________  |
| | полка: [банка]  ||
| | [тетрадь][радио]||
| |    ( тава )     ||
| |_миска: o o o____||
|   O            O   |
|  пёс спит          |
+--------------------+
```

**2. Работа** — основной экран, большая часть времени. Гость по плечи в верхней трети, стенд в нижних двух третях. Постоянных кнопок нет.

```
+--------------------+
|      ( Сом )       |
|  тук-тук по краю   |
|====== стойка ======|
|     (  ТАВА  )     |
|     ( ~роти~ )     |
|--------------------|
|   +------------+   |
|   |    лист    |   |
|   +------------+   |
| миска: o o   масло |
+--------------------+
```

**3. Ответ** — после подачи вид сам поднимается к лицу. Ни звёзд, ни слов. Еда едет на полку.

```
+--------------------+
|                    |
|     ( лицо )       |
|   глаза закрыты    |
|   ХРУСТ  . крошки .|
|        ^           |
|   [ тарелка ] веди |
|====== стойка ======|
|  [банка варенья]   |
|  миска: o o        |
+--------------------+
```

**4. Тетрадь** — лист выезжает снизу, закрывается касанием. Слева рука Мали, справа мои роти. Пустых рамок и счётчиков нет.

```
+--------------------+
|  (сцена затемнена) |
| .--------.-------. |
| | Мали:  | моё:  | |
| |  \|/   | [снимок |
| | -роти- |  роти]| |
| |  /|\   | (банка)||
| | (Сом)  |  дождь| |
| '--------'-------' |
|  < листать >       |
+--------------------+
```

**5. Ночь** — конец вечера. Одна перемена подсвечена тем, что лежит не так, как вчера. Ком теста — вход в следующий вечер.

```
+--------------------+
|  *   ночь   *   *  |
|  ________________  |
| | полка:[банка]+1 ||
| | (тава под крышк.)|
| |_________________||
|  сегодня:          |
|  [##] [#.] [..]    |
|   Сом  Сом  пёс    |
|    ( ком теста )   |
+--------------------+
```

**Пауза** — та же крышка на таве. **Служебное** — старое радио на тележке: громкость, «начать заново», номер сборки обычным текстом. Это единственное место со словами (служебный текст разрешён 19.09).

## Гости и скрытые вкусы

- Гость не заказывает и не показывает значков. Он показывает **себя**: один жест и вещь в руке. Игра знает его вкус, но не показывает (07.09).
- У человека 2–3 скрытые черты вкуса; за раз проявляется одна. Сом: громкий хруст (первые вечера), потом — «без сахара сверху».
- У каждого свойства роти свой способ ответа, одинаковый у всех людей — его выучиваешь один раз: хруст — звуком и глазами; начинка — разламывает и заглядывает; верх — облизывает пальцы или стряхивает. Гость показывает, **что** заметил, а не «насколько хорошо».
- Порог честный: мягкое роти получает вежливый кивок, а не восторг. Иначе не видно разницы и непонятно, зачем стучали по таве.
- Во время жарки гость меняет позу, когда роти переходит на следующую ступень — подсказка «теплее» без значков.
- «Не то» роти не пропадает: его получает пёс, сосед или я сама. Ошибка — история про другого едока.
- В первой версии гость один — Тётя Сом, четыре неподвижные картинки. Плой с колокольчиком — следующая.

## Что растёт со временем

Чисел, уровней, денег, ежедневных наград нет. Растут три вещи.

1. **Полка.** Новые вкусы приходят только от людей: варенье Сом, бананы, позже чья-то соль. Запас виден и кончается. Простое роти (масло, сгущёнка) можно сделать всегда.
2. **Тетрадь.** Каждый вечер — разворот со снимками моих роти. Через две недели по ней видно, как изменились руки. Игра это не оценивает.
3. **Круг людей.** Человек меняет не шкалу, а поведение: Сом сначала стоит, потом приносит свой табурет. Вещь для тележки человек дарит только при такой перемене; еду оставляет каждый раз.

Примерный ход: вечера 1–3 — Сом и хруст; 3–5 — Плой, колокольчик, бананов не хватает на всех, двое гостей в один вечер; дальше, только после «тянет ещё», — гости вдвоём (разные куски сетки разным людям), погода, приезд Мали.

Пропустила неделю — ничего не отнимается.

## Первые 10 минут

Без единого слова, без стрелок и подсветок.

- **0:00** — тёмная тележка, лампа чуть мерцает: единственное движение на экране. Касание — свет.
- **0:20** — в миске три шарика, никого нет. Пёс смотрит на миску. Первое роти делаешь без зрителя; порвала — дырка остаётся узором.
- **~2:30** — пока жарится, из сумерек приходит Сом — на запах. Смотрит на таву, стучит по краю.
- **~4:00** — единственное, что можно сделать с тарелкой, — повести её к Сом. Она отламывает край, звук мягкий, вежливый кивок. Оставляет бананы. Остаётся и садится у стойки.
- **~4:30** — тетрадь приоткрылась: у Мали роти нарисовано с лучами хруста, у моего снимка лучей нет. Никто не говорит «подержи дольше».
- **5:00–9:00** — второй шарик. Подержала дольше — громкий хруст, закрытые глаза, банка варенья. Нет — снова кивок; вечер от этого не хуже.
- **9:00–12:00** — третий шарик. Сом ушла, пёс кладёт морду на стойку.
- **~12:30** — миска пуста, рядом с тавой появилась крышка. Накрыла — ночь.

Главный риск: поймёт ли человек без подсказки, что стук по таве значит «хочу хрустящее». По тексту это не оценить.

## Банк идей

**Встреча**
- Гость подходит во время жарки, а не до готовки — *пробовать первым*
- Второй шанс: вежливо съевшая Сом остаётся на второй шарик — *пробовать первым*
- Гость меняет позу по ступеням жарки — *пробовать первым* (проверить, не торопит ли)
- Свой способ ответа на каждое свойство роти (хруст, начинка, верх) — *потом*, по одному
- Один человек приходит в разных состояниях (зонт, пустая банка) — *потом*
- Гости вдвоём, одно роти на двоих — *потом*
- «Роти в дорогу»: готовишь тому, кого ещё не видела, ответ придёт завтра — *потом*
- Намёк взглядом на бананы вместо жеста — *спорно* (мелко для телефона)

**Вечер и ритм**
- Третий шарик ничей: псу, себе, на ограду — *пробовать первым*
- Небо темнеет по шарикам вместо часов — *пробовать первым*
- Крышка на таве как пауза и возврат — *пробовать первым*
- Роти на ограде утром пропало, остался след (перо, чешуйка) — *потом*
- Тихий вечер без гостей, только дождь и пёс — *спорно* (может показаться пустотой)
- Открытие и закрытие по три жеста, деление кома на шарики на завтра — *спорно* (на десятый вечер — трение)

**Память и вещи**
- Тетрадь хранит настоящий снимок моего роти, не сводку словами — *пробовать первым*
- Вчерашний подарок — сегодняшняя начинка, запас виден и кончается — *пробовать первым* (со второго вечера)
- Картинка из жизни гостя проступает на полях без пустых рамок — *потом*
- Вещи тележки дают новые ситуации (столик — двое садятся вместе), а не бонусы — *потом*
- Вещь-слух: гость оставил чужую вещь, завтра приходит хозяин — *потом*
- Разворот тетради сохраняется картинкой в «Фото» — *потом*
- Вещи с функцией (колокольчик выбирает гостя, миска побольше) — *спорно* (это улучшения, а не память)
- Черты человека проявляются чернилами на странице — *спорно* (шкала под другим именем)

**Оболочка**
- Меню нет, тележка и есть меню: лампа, тетрадь, радио — *пробовать первым*
- Запуск с домашнего экрана на весь экран, автосохранение после каждого шага — *пробовать первым*
- Силуэт завтрашнего гостя на ночном кадре — *спорно* (сообщает о возможном)
- Рука-призрак, показывающая жест при бездействии; лампа-указатель — *спорно* (подсветка цели отклонена 07.09 — решение ⚑ ассистента по её поручению «сама отвечай», не её слова)
- Выбор брата или сестры первым кадром — *спорно* (решение до того, как что-то понятно)
- Приезд Мали как мягкий конец главы — *потом* (вопрос о конце игры открыт, #66)

## Первая играбельная версия

Всё в отдельной ветке, не на публичной странице. После каждого шага — сборка, которую можно открыть на iPhone. Дни — оценка.

| Шаг | Срок | Что появляется | На что смотрим |
|---|---|---|---|
| 0 | 1–3 дня | Починен жест (#91): лист не улетает на таву от медленной протяжки. Заодно сверено, что хруст, который считает стенд, совпадает с тем, что видно на экране. | Ввод не раздражает. |
| 1 | 2 дня | Рамка вечера без гостя: вертикальный экран, запуск с домашнего экрана, миска на три шарика вместо «заново», лампа — старт, крышка — конец и пауза, небо по шарикам, автосохранение. | Нашла ли вход сама; кончается ли вечер сам. |
| 2 | 2–3 дня | Тётя Сом: четыре неподвижные картинки, приходит во время жарки, стучит, подача ведением, два честных ответа, еда на стойке, второй шанс. | Видна ли разница ответов без слов и без звука. |
| 3 | 1–2 дня | Тетрадь: снимок моего роти и один рисунок Мали. | Открывает ли она тетрадь сама. |
| 4 | 1 день | Третий шарик: пёс или ограда. Ночной кадр. | Тихая точка или пустота. |
| 5 | 2 дня | Второй вечер другой: вчерашняя еда на полке, её мало; Сом с пустой банкой. | Начинает ли она второй вечер. |

Вопрос к владелице после показов один: «тянет сделать ещё» или «скучно / раздражает». Остальное агент считает по журналу стенда: на каком шарике она вышла, изменила ли прожарку после тетради, начала ли второй вечер, куда увела третье роти.

Запасной выход: если Сом не читается, остаётся шаг 1 плюс тетрадь — проверяем вечер как тихий ритуал без гостя.

Не входит: Плой, квадратный лист 16.11 (отдельной веткой, чтобы не менять две вещи сразу), ритуалы из трёх жестов, выбор начинки, вещи тележки, погода, подсказки, намёк на завтра, выбор героя, карта.

Ограничения iPhone, не решения: вибрации в браузере нет; звук включается только после первого касания и глушится переключателем «без звука» — поэтому каждый ответ читается глазами.

## Что проверяем игрой

1. Читается ли стук по таве как «хочу хрустящее» — без значков и с выключенным звуком.
2. Заметна ли разница между «узнала своё» и «вежливо»; не обидно ли получить «вежливо» на первом роти.
3. Гость, который смотрит на таву, — компания или давление.
4. Находит ли она вход без кнопки «Играть»; сколько секунд до касания лампы (по журналу).
5. Темнеющее небо — уют или таймер.
6. Три минуты жарки с гостем рядом — встреча или ожидание.
7. Хватает ли одной черты на три шарика, или второй уже повтор.
8. Третий шарик без гостя — тихая точка или пустота.
9. Понятно ли без слов, что банка на полке — еда, которая кладётся в роти и кончается.
10. Читается ли лицо гостя в верхней трети экрана её телефона.
11. Снимок в тетради — «моё роти» или «скриншот».
12. Жест подачи не путается со взмахом на таву.

Организационное, не к владелице: как дать ветку на iPhone вне домашней сети, не вливая в `main` (локальный предпросмотр на порту 8781 работает только дома).

### 2. Чего не хватает для первой сессии

1. **Экран гаснет во время жарки.** Три минуты без касаний, автоблокировка iPhone наступит раньше. Нужно удержание экрана (Wake Lock) или повод трогать.
2. **Прерывание посреди жеста.** Крышка закрывает только жарку. Не описано, что с листом в руках или в полёте, с гостем посреди ответа, с открытой тетрадью.
3. **Возврат = перезагрузка страницы.** iOS выгружает веб-приложение, поэтому «сняла крышку и продолжила» требует полного восстановления сцены из сохранения. «Вернулась через неделю» упирается в очистку хранилища Safari — не проверено.
4. **Звук.**
   - Нет быстрого выключения: громкость только в радио, которое надо найти.
   - Не сказано, глушит ли игра её музыку или подкаст.
   - После звонка звук в вебе не возвращается сам, нужно касание.
5. **«Сожгла все три» невозможно, а настоящий худший случай не описан.** По 20.09 роти не чернеет. Худший случай — три мягких роти и два вежливых кивка. Что тогда покажет ночной кадр?
6. **Противоречие внутри черновика.** Ночь обещает «одну новую вещь» каждый вечер, а раздел «Что растёт» — что вещь дарят только при перемене в человеке.
7. **Промах и порча.** «Шарик потерять нельзя» — но не сказано, что происходит, если лист упал мимо тавы или порван в клочья.
8. **Игрок не подаёт.**
   - Ждёт ли Сом вечно?
   - Что, если первое роти отдано псу у неё на глазах?
   - Что, если подано сырое, с первой минуты?
9. **Второй шарик при удаче с первого.** В таблице «второй шанс или другой едок», но гость в первой версии один. Кому?
10. **Третий шарик: три цели без значков.** Пёс, я сама, ограда — как их различить и как «съесть самой» жестом?
11. **Тетрадь открывается сама трижды за вечер.** Рвёт ритм. Что на левой странице у третьего роти, если гостя нет?
12. **Конец приложения.** «Не тронула — можно закрывать» без слов никак не сообщается. Не сказано, что она увидит при следующем запуске: ночной кадр или сумерки.
13. **«Начать заново» в радио.** Стирает ли всё — тетрадь, полку? Нужна защита от случайного касания, а это ещё слова.
14. **Первый запуск идёт не с иконки.** Сначала Safari и «На экран Домой» — шаг со словами вне игры. В Safari свайп от края («назад») спорит с ведением тарелки.
15. **Арифметика вечера.** Три роти по три минуты — это 9 минут ожидания из 13. В хронологии подача в ~4:30, то есть ровно три минуты на таве, хруст выходит сам. В «Первых 10 минутах» подача в ~4:00. Версии расходятся.
16. **Подсказка приходит поздно.** Сом стучит на второй минуте, когда толщина и масло уже выбраны. Влияет только время на таве — это стоит назвать прямо.
17. **Несколько вечеров подряд.** Еда на полке копится без предела, «её видимо мало» перестаёт работать.
18. **Мелкое лицо.** Запасного канала нет, если мимика в верхней трети не читается.
