## 🎯 Вердикт

### ❌ Touch.radiusX НЕ осмыслен для механики

**Вывод:**  
`Touch.radiusX` на iOS Safari 26.6.1 возвращает **константу 24.17** независимо от:
- Способа касания (три разных жеста)
- Количества контакта
- Интенсивности нажатия

Это подтверждает W3C спецификацию: *«0 if no value is known»* — iOS исторически возвращает константу вместо реальной площади пятна.

### Следствие для дизайна

**НЕ проектировать механику на основе `Touch.radiusX`** (площадь касания).

**Альтернатива (как в дизайн-доке):**
- Давление во времени: интеграл `∫ dwell dt` при малой скорости пальца
- Тактильный отклик пропорционален текущей деформации
- Работает на 100% устройств и тренируется
