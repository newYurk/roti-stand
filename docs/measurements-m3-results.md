## Результаты производительности

### Атлас

- **Размер на экране:** 8192×1280 px
- **Размер файла:** 3.93 MB
- **Объём VRAM:** ~40 MB (приемлемо)

### Генерация и упаковка

- **Генерация кадров:** 32.0 ms
- **Упаковка в атлас:** 1.0 ms
- **Загрузка Image:** 5.0 ms

### Рендеринг

- **FPS:** 59.7 fps ✅ (отлично, >55)
- **Frame time:** 16.76 ms ✅ (хорошо, <18 ms)

## Оценка

✅ **Вердикт: поддерживает выбор WebGL/Canvas 2D стека**

Атлас размером 8K×1.3K с 400 кадрами (160×160 px, 25.6M пикселей) на iPhone 18.7:
- Файл занимает менее 4 MB (приемлемо для сжатия WebP ещё меньше)
- VRAM потребление в пределах норм для мобилей
- Рендеринг стабильно выше целевого порога (60 fps стремимся, 59.7 достаточно)
- Frame time предсказуем и низкий (16.76 ms)

Пропускная способность GPU и цельность frame time подтверждают, что:
1. WebGL context с atlased rendering — жизнеспособен
2. Объём v1 «первый день» (8 ингредиентов, персонажи, UI) в пределах бюджета
3. Дальше тесты по звуку (М2), слайдам ввода (М1), и арту (М4–М5)
