## Что это

Кулинарный симулятор с ASMR-слоем: одна вечерняя тайская макашница с роти на тропическом острове. Ядро — превратить комок теста в тонкую золотистую вещь руками; тактильность держится на звуке, а не на картинке. Скрытая географическая привязка для разработки — **Ко Чанг**; игроку не сообщается.

Остальное — в `docs/roti-design-doc.md`. Пересказывать его здесь нельзя: этот файл — навигация, не дизайн.

## Про корпус и ревью — коротко

- **Ревью корпуса 21–22.08.2026** (`review/review-2026-08-21.md`, восемь линз, 175 находок) — старший по тому, что в корпусе неверно. Его главные удары — `Touch.force` мёртв на всех iPhone с 2019 года, подброс не пройдёт App Store, корпус в 6,4 раза больше ядра — уже впитаны в дизайн-док и решения.
- **`docs/corpus-map.md`** — инвентарь документов. **Утрачено минимум два** (`addendum v5`, `addendum-v3`); на диске их нет, единственный шанс — история чатов Perplexity, проверить может только пользователь.

## Стек не выбран

Своего `DECISION.md` у проекта нет — это следующий этап. Решение по «Лягушке» (Canvas 2D + WebAudio, один файл, Capacitor) **на Roti не распространяется**: там тайминговая игра почти без ассетов, здесь — ассетный симулятор с ASMR-звуком и симуляцией теста. Дисквалификация Godot из `../night-skip/DECISION.md` не наследуется; его реальная проблема для Roti — GDScript даёт ~200 узлов сетки против нужных 1 000–1 200, то есть требует GDExtension на C++. Стенд-прототип аргументом за веб-стек не является: решение — после замеров M1–M5.
